Seanime Denshi — Quickstart

First-time setup on Windows  ·  mpv playback + ffmpeg/LAN streaming + online streaming (Anikoto)  ·  for v3.8.30 and later

1Download & install

  1. Go to github.com/itsRevela/seanime/releases/latest and download seanime-denshi-3.8.30_Windows_x64.exe (the version number may be higher later — always grab the latest).
  2. Run it. The installer is unsigned, so Windows SmartScreen will complain: click More info → Run anyway, then accept the admin (UAC) prompt.
  3. Launch Seanime Denshi. It starts its own local Seanime server automatically. Sign in with your AniList account when asked, and set your anime library folder under Settings → Library if you want local files/downloads.
Upgrading later: just run the newer installer over the existing install. Never uninstall first — uninstalling deletes the app's data. This build intentionally has no auto-updates; new versions always come from the same releases page.

2mpv — full playback functionality

  1. Install mpv: open a terminal and run winget install --id shinchiro.mpv -e --source winget (no admin needed). If winget ever asks which package, pick “mpv (shinchiro build)” — not the Microsoft Store one, and not mpv.net. (Alternatively download a build from mpv.io.)
  2. Launch mpv once by itself (run mpv in a new terminal, or drop a video onto mpv.exe), then close it. This warms up Windows' first-run checks. Tip: where.exe mpv prints the installed path — handy for the override field below.
  3. In Seanime: Settings → Playback → under Video playback, turn on “Use local mpv on this device”.
  4. If mpv isn't on your PATH, fill in “mpv path override” with the full path to mpv.exe (e.g. C:\Program Files\MPV Player\mpv.exe). Start with “Extra mpv args” empty — a single bad flag there makes mpv exit instantly.

You get: playback in real mpv with episode playlists (</> for prev/next), resume-from-last-position, automatic AniList progress sync when you finish an episode, and screenshots saved to Pictures\seanime.

Optional — buffering/tuning flags: once everything works, you can put this proven set into “Extra mpv args”:
--cache=yes --cache-secs=300 --demuxer-readahead-secs=60 --demuxer-max-bytes=2GiB --network-timeout=60
It buffers up to 5 minutes / 2 GiB ahead and tolerates slow reads — mainly useful when mpv streams over a network (remote server, slow NAS). On an all-local setup like this one it's optional; add it if you ever see stutter on high-bitrate files.
Type these flags in by hand — do not copy them out of this PDF. PDF copy-paste often turns the double hyphens (--) into a dash character mpv doesn't understand, and a single bad flag makes mpv exit instantly with “mpv exited (code 1)”. If mpv stops launching after editing this field, clear it first.

3ffmpeg — transcoding & LAN streaming

Needed for playing in a web browser (direct play/transcoding) and for streaming to other devices on your network.

  1. Run winget install Gyan.FFmpeg in a regular terminal (installs both ffmpeg and ffprobe).
  2. Fully quit Denshi and relaunch it — quit from the tray icon if it minimizes to tray. The server only sees the new PATH after a restart. (Alternative: skip PATH entirely and set FFmpeg path / FFprobe path explicitly under Settings → Media Streaming, e.g. C:\ffmpeg\bin\ffmpeg.exe.)
  3. Tune Settings → Media Streaming: pick a Transcode preset, and enable hardware acceleration if you have an NVIDIA/Intel GPU. CPU works fine to start.

To watch from other devices on your LAN (phone, TV, another PC):

  1. Open %APPDATA%\Seanime\config.toml (paste that into the Explorer address bar) and under [server] set:
    host = '0.0.0.0'  and add  password = 'pick-something' (strongly recommended once it's reachable beyond this PC).
  2. Restart Denshi. If Windows Firewall asks, allow access (or add an inbound rule for TCP port 43211).
  3. On the other device, browse to http://<this-PC's-IP>:43211 and log in with the password.
Note: the server lives inside Denshi — it runs only while the Denshi app is open. Keep Denshi running (tray is fine) while others are streaming.

4qBittorrent — downloading to your library

Seanime talks to qBittorrent through its Web UI API, so it's two steps: turn that on in qBittorrent, then point Seanime at it.

In qBittorrent (install from qbittorrent.org if you haven't):

  1. Tools → Options → Web UI → check “Web User Interface (Remote control)”.
  2. Leave the port at 8080 (note it down if you change it — the two sides must match).
  3. Either set a username + password, or check “Bypass authentication for clients on localhost” (simplest, since both apps run on this PC).
  4. Click OK and leave qBittorrent running.

In Seanime — Settings → Torrents / Torrent Client:

  1. Default Torrent Client: qBittorrent. (Leave the torrent search Default Provider as it is — AnimeTosho works out of the box.)
  2. Host: 127.0.0.1  ·  Port: 8080
  3. Username / Password: whatever you set in the Web UI — leave both empty if you used the localhost bypass.
  4. Executable: (optional but recommended) full path to qbittorrent.exe, usually C:\Program Files\qBittorrent\qbittorrent.exe — lets Seanime auto-launch qBittorrent when it's not running.
  5. Tags / Category: optional — e.g. category seanime to group Seanime's downloads inside qBittorrent.
  6. Save. Make sure your library folder is set (Settings → Library) — finished downloads land there and get matched into your library automatically.

Test it: open any anime → download an episode via the torrent search. Seanime hands the torrent to qBittorrent, shows progress in its torrent list, and the episode appears in your library when done.

5Online streaming with Anikoto

  1. Settings → Online Streaming → turn on Enable (“Watch anime episodes from online sources”).
  2. Open the Extensions page → Marketplace → paste this into the Marketplace URL field:
    https://raw.githubusercontent.com/Bas1874/Seanime-Marketplace/refs/heads/main/Marketplace/Main.json
  3. Find “Anikoto” by aquaryuo (id aq-anikoto — pick this one if more than one Anikoto is listed) and click Install.
  4. Open any anime → Stream online → choose Anikoto as the provider. Episodes play in the built-in player (this is the path that needs ffmpeg-free HLS only — no extra setup).
About dubs: “Switch to dub” depends entirely on the source site. If a dub errors out or plays Japanese audio, the site's dub for that episode is missing or lagging behind — try another provider from the marketplace, or check the Extensions page for provider updates. Not a Seanime problem.

6If something breaks

SymptomFix
SmartScreen blocks the installer More info → Run anyway (expected — the build is unsigned).
mpv error: “IPC socket…” or “mpv exited (code N)” Check the mpv path override points at a real mpv.exe (not mpv.net), clear “Extra mpv args”, launch mpv once manually, retry.
“ffprobe: executable file not found in %PATH%” ffmpeg isn't visible to the server — fully quit & relaunch Denshi after installing, or set the explicit FFmpeg/FFprobe paths in Settings → Media Streaming.
Seanime can't connect to qBittorrent qBittorrent must be running with the Web UI enabled; the port in Seanime must match Tools → Options → Web UI (default 8080). If you set Web UI credentials, mirror them in Seanime.
“Failed to load subtitle track” on online streaming Fixed in v3.8.30 — make sure you're on 3.8.30 or newer.
An update popup appears It shouldn't (updates are disabled in this build, v3.8.29+). If you see one on an older version, ignore it — never install updates from inside the app; they would replace this build with the upstream one.
Anything else Logs: %APPDATA%\seanime-denshi\logs\main.log (app) and %APPDATA%\Seanime\logs\ (server). Send the latest one over.
